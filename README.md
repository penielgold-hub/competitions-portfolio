#### Project overview

Ghost Lantern is an educational application that presents three perspectives on a payment scenario:

- **Sender:** a browser-local sample payment simulation.
- **Observer:** a view of public transaction records retrieved from the Tari Ootle Esmeralda testnet indexer.
- **Recipient:** a browser-local view of the sample payment.

The Sender and Recipient examples are simulations. They do not create, sign, submit, or transfer Tari transactions. The Observer's live network records are separate from the local sample. Ghost Lantern is a learning tool; it does not prove that a transaction is private or demonstrate a real payment.
